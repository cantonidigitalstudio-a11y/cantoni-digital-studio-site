# Device QA

Area per prove visuali su device reali o browser/device remoti.

Gli screenshot sono evidenze locali e sono ignorati da git. Quando un controllo
porta a una decisione importante, registra il risultato in un file markdown o in
`sales-kit/daily-ops/`, non solo nello screenshot.

Checklist minima:

- homepage;
- preventivo;
- portfolio/case study;
- privacy e termini;
- link WhatsApp/social;
- assenza di overflow orizzontale evidente.
